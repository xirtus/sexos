# JetBrains Mono

JetBrains Mono by JetBrains (Regular, Bold, Italic and Bold Italic), version 2.304, from
https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304. Licensed under the SIL
Open Font License 1.1 (`OFL.txt`). Spindle offers it with `font = jetbrains-mono` in
`spindle.conf`; its coding ligatures (`->`, `=>`, `!=`, `<=` and the rest) are contextual
alternates that keep one glyph per cell, so they fit the terminal grid. `crates/sex-font`
embeds these files unchanged; only programs that name them carry them.
