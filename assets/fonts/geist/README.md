# Geist

Geist Sans and Geist Mono by Vercel, version 1.9.2, from
https://github.com/vercel/geist-font. Licensed under the SIL Open Font License 1.1
(`OFL.txt`). SexOS renders Geist Mono into a fixed glyph table at build time with
`scripts/make_font.py`; the table is generated, the fonts here are the source.
