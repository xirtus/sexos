# Date keyboard shortcuts

Press **?** inside Date to open the same reference. Use Up/Down or Page Up/Down
to scroll it, then **?** or **Escape** to close. Typing an event or alarm name
keeps the help key as ordinary text until that entry is finished.

| Where | Keys | Action |
| --- | --- | --- |
| Any view | M, W, D, C, L | Month, week, day, clock, calendars |
| Any view | S | Sync a linked CalDAV account |
| Any view | V | Review retained local CalDAV conflicts; press again for the next |
| Conflict review | L or S, then Enter | Keep the local or server copy; Enter stages and saves the choice. A local choice is sent on the next sync. Escape cancels the choice. |
| Calendar views | Ctrl+Z, Ctrl+Y | Undo or redo local event additions, copies and removals; sync clears this history |
| Clock | Ctrl+Z, Ctrl+Y | Undo or redo world-zone and alarm changes in order; fired alarms and live timers are outside this history |
| Any view | E | Export shown events to `date-export.ics` |
| Notice showing | Shift+S | Snooze the notice for five minutes; it survives a Date restart |
| Month | Arrow keys | Move one day or one week |
| Month | Page Up, Page Down | Previous or next month |
| Month, week, day | T or Home | Return to today |
| Month, week, day | Enter | Open the chosen day's agenda |
| Month, week, day | N | Add an event to the chosen day; start with `HH:MM` for a timed event |
| Open agenda | Up, Down | Choose an event |
| Open agenda | Delete | Remove the chosen event |
| Open agenda | D | Copy the chosen occurrence to tomorrow as a separate event, then open tomorrow's agenda |
| Open agenda | Shift+D | Copy the chosen occurrence to a YYYY-MM-DD date as a separate event |
| Open agenda | M | Move a personal, nonrecurring event to a YYYY-MM-DD date; linked events sync the change |
| Open agenda | A, X | Prepare accepting or declining an invitation and open a reply preview |
| Reply preview | Enter | Queue the local reply file and update the invitation |
| Reply preview | Escape or Ctrl+Z, then Ctrl+Y | Cancel the choice, then restore it before queueing |
| Open agenda, outside a reply preview | Escape or Enter | Return to the calendar |
| Week, day | Left, Right | Move one day |
| Week, day | Up, Down | Scroll through hours |
| Week, day | Page Up, Page Down | Previous or next week |
| Clock | N, R | Add an alarm or timer |
| Clock | Z, H | Add a world zone or set the local zone |
| Clock | Space, Delete | Toggle an alarm or remove the chosen item |
| Calendars | N | Add a local calendar |
| Calendars | Space or Enter | Show or hide the chosen calendar |
