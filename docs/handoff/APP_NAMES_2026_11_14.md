# App names: the rename table (2026-11-14)

Rule: `docs/DESIGN_GUARDRAILS.md` section 6. This file tracks every rename and its state.

## Duplicates: the better implementation keeps the themed name

| Themed name | Old themed code | Newer plain program | Decision |
|---|---|---|---|
| Kaleidoscope (browser) | `apps/kaleidoscope`: the BOOT-catalog browser (TLS/HTTP probes, text reader, docx import) | `apps/web`: sex-html layout, CSS, JS (QuickJS), canvas, WebGL, WebGPU, media, tabs | **Web becomes Kaleidoscope.** The BOOT browser is retired from the catalog; its document import moves to Quil/Jot. |
| Qupid (media player) | `apps/qupid`: a 93-line stub | `apps/play`: FFmpeg video and sound, subtitles, playlists (PR #183) | **Play becomes Qupid.** The stub is removed. Music (G3) becomes Qupid's library view. |
| sexshop (app store) | `servers/sexshop`: a stub that does not compile | `apps/store`: the package catalog window | **Store becomes the `sexshop` program.** The stub server is removed. |
| Quil (code editor) | `servers/quil`: the BOOT editor | `apps/sex-edit`: an 83-line stub | **Quil stays.** The stub is removed. Jot stays the notepad. |
| Mesh (system overview) | Mesh launcher row: "SYSTEM OVERVIEW", a status stub | `apps/monitor`: CPU and memory per service (syscall 87) | **Monitor becomes Mesh.** The launcher's Mesh row opens it. |
| Spindle (terminal) | `apps/spindle`: the command surface | Term (F1, PR #182): a VT/xterm terminal | **Term becomes Spindle's terminal window**; the command surface is its built-in shell. |

Stubs removed with no successor: `apps/sex-hub` (its labels Files/Editor/Calculator/
Browser/Player were the plain names), `apps/sex-files`.
