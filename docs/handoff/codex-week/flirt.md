# Flirt daily-driver gaps

Compared with FaceTime and Signal calling, Flirt currently exposes SexOS TCP,
UDP, IPv4 and IPv6 diagnostics through a native window. The app-name plan keeps
Flirt for voice and video; Valentine owns mail.

Remaining gaps:

- A contact list and call invitations.
- Encrypted real-time audio and video, device selection, call controls and
  notifications.
- NAT traversal and network recovery.
- A polished native call interface, call history, keyboard reference, theme
  support, undo where applicable and crash-safe session state.

This change corrects the visible app title from the retired Talk name to Flirt
and verifies it in the existing IPv6 QEMU gate.
