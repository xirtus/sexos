# Vellum shortcut reference

Ctrl+Shift+/ opens a keyboard reference drawn over the document. Escape closes
it, and the page remains in place. The help overlay uses Vellum's theme tokens.
`docs/apps/vellum-shortcuts.md` lists the active controls and distinguishes
typed visual markup from a digital signature.

The documents QEMU gate opens and closes the reference, checks the app records,
and captures `pdf-shortcuts.ppm`. Full builds and QEMU run on GitHub CI.
