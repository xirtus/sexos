## Keyboard layouts, dead keys, AltGr and Compose (A1–A5, 2026-11-13)

Workstream A of `DAILY_DRIVER_NEXT_100_SLICES.md`. Anyone can now type their language.

**Try it.** Super+Ctrl+Space steps through US, German, French, Spanish, UK and Russian; the
panel says `Keyboard: DE  German`. In Jot, Web (page and address bar), Files names, Quil and
`std` programs' input lines: `ü ß ö ä` on a German keyboard, `é` from dead `´` then `e`, AltGr+Q
for `@`, Caps Lock for capitals only, and Compose (the Menu key, or right Alt on layouts with no
AltGr level such as US) for `o "` → `ö`, `= e` → `€`, `s s` → `ß`, `- - -` → `—`, `1 2` → `½`.

**What changed.**
- New crate `crates/sex-keymap` (no_std, no allocation): 15 layouts (us, us-intl, gb, de, fr, es,
  it, pt, se, fi, no, dk, us-dvorak, us-colemak, ru), four levels per key, dead keys as combining
  marks, Caps Lock, Compose. Tables for dead-key letters (331) and Compose sequences (715) are
  generated from Unicode decompositions by `scripts/gen_keymap_compose.py` (our own data).
- Shell keeps one `Keyboard` (`servers/silk-shell/src/keyboard_layout.rs`) and puts what each
  press typed into the key it hands the focused program. AltGr, Caps Lock and Compose never
  reach programs.
- **ABI**: `sex_pdx::app_key::Key` gains `text: Text` (`Us`, `Nothing`, `Char`). Wire bit 17 says
  the word carries text; bits 32..53 hold the scalar. Shell sends the old wire whenever the key
  types what a US keyboard types, so programs built before this keep working on US.
  `sex_app::text(key)` returns the character; `sex_app::typed` stays ASCII-only.
- Input: PS/2 right Ctrl (E0 1D) and right Alt (E0 38) now get the USB codes 0x61 and 0x64, so
  AltGr is distinct from Alt on every keyboard. Ctrl+Alt display scale also takes right Ctrl.
- `WmAction::KeyboardLayout` on Super+Ctrl+Space.

**Tests.** `cargo test -p sex-keymap` (every layout parses; US equals the old table key for key;
golden keys per layout; dead keys; Caps Lock; Compose; switching). `tests/app_input.rs` runs the
actual Shell dispatch: DE gives `z`/`ü`, dead `´`+`e` gives `é`, AltGr+Q gives `@` and AltGr itself
is not delivered, Super+Ctrl+Space is the layout action, wire round-trips with text. QEMU:
`scripts/keyboard_layout_gate.py` (types `üé@zö` in Jot on DE and checks the saved bytes).

**Next.** Shortcuts still follow key positions (Ctrl+Z is the key labelled Y on DE); the chosen
layouts come from Settings once B1 lands (A10); Spindle and the launcher still read US.

## Fallback fonts: Cyrillic, Greek, CJK, emoji, symbols (A6, 2026-11-13)

Display's text cells drew only what Geist or the old bitmap font has. Now `glyphs::mono_cell`
tries, after Geist Mono: Noto Sans Mono (Latin extended, Greek, Cyrillic, IPA), the emoji of
Noto Color Emoji (1,439, as shaded 36x36 coverage tinted like text), Noto Sans Symbols 2, then
Noto Sans CJK SC cut to GB2312 + JIS X 0208 + KS X 1001 + Big5 level 1 (about 14,000
characters). `crates/sex-font/src/fallback.rs`; fonts in `assets/fonts/noto/` (OFL 1.1), built by
`scripts/gen_fallback_fonts.py` from Ubuntu's Noto packages. Display grows by about 5 MB.
Wide characters are fitted into one cell (the grid is one cell per scalar); double-width cells
and fallback for title/UI text (Geist Sans) are next. Host: `cargo test -p sex-font --test
fallback` (Ж 日 あ 한 國 😀 👍 ❤ 🚀 ♞ ⣿ each come from the right font with ink at three cell sizes).

## Arabic, Hebrew, Indic and Thai text; shaping, bidi and Pinyin (A6–A9, 2026-11-13)

**Fonts.** The fallback chain gains Noto Sans Arabic, Hebrew, Devanagari and Thai, and title/UI
text (Geist Sans) now falls back too: Display's sans layouts read UTF-8 and draw any scalar from
the outline fallbacks or the emoji set. `TITLE_MAX` is now 128 bytes.

**Shaping and bidi (A7, A8).** New crate `crates/sex-shape`:
- `bidi`: the Unicode bidi algorithm for one line, without allocation (Display has no
  allocator): W1–W7, N0 bracket pairs, N1–N2, I1–I2, L1, L2 and mirroring. Matches the
  `unicode-bidi` crate (test-only) on 24 mixed lines.
- `arabic`: joining forms (isolated, initial, medial, final) from Unicode's joining data, so cells
  show connected Arabic; `cells::reorder_lines` puts each text line in visual order and
  `cells::shown` gives the form to draw. Display calls both.
- `shape` (feature `shaping`): rustybuzz 0.20 for full OpenType shaping; 21 strings (Arabic,
  Hebrew, Devanagari, Thai, Latin ligatures, emoji) give the same glyphs, clusters and advances as
  `hb-shape` (`tests/data/hb_reference.tsv`, from `scripts/gen_shape_reference.py`).
- Tables generated by `scripts/gen_shape_tables.py` from Unicode data.

**Pinyin (A9).** New crate `crates/sex-ime` (GPL-3.0-only, dictionary from pyim-basedict, 34,963
words, `scripts/gen_pinyin_table.py`). Layout `zh-pinyin` (panel `PY`) is in the Super+Ctrl+Space
cycle: letters build a syllable string shown on the panel with nine numbered candidates; Space or
1–9 commits a word, Enter commits the letters as typed, Backspace edits, Escape cancels, `-`/`=` page. Committed characters reach the program
as text keys (**ABI**: `app_key::KEY_TEXT = 0x7E`, a key that only carries text).
`tests/app_input.rs` types `nihao` and Space through the real Shell dispatch and gets 你好.

**Tests.** `cargo test -p sex-shape --features shaping`, `cargo test -p sex-ime`, the fallback test
now also checks ب ﺳ ש न ก.

**Next.** Display cells are one per scalar: double-width CJK cells and full rustybuzz shaping in
Display (it needs an allocator) remain. A10 (repeat, Caps-as-Ctrl from Settings) waits for B1.

## Double-width cells and layout-aware shortcuts

**Wide cells.** CJK, Hangul, fullwidth forms and emoji (Unicode East Asian Width W or F, minus
marks and format characters) take two Display cells. `sex_shape::cells::is_wide` reads a range
table generated into `crates/sex-shape/src/wide_table.rs` by `scripts/gen_shape_tables.py`; a host
test compares it with the `unicode-width` crate (dev-only, MIT/Apache) over U+1100..U+2FFFF.
Display's `recompute_text_lines` pushes a wide scalar's byte offset twice, wraps before it when it
would split, and draws one glyph across both halves (`glyphs::MAX_W` 192). In right-to-left rows
`reorder_lines` moves the pair as one. Tests: `crates/sex-shape/tests/text.rs`,
`tests/display_text_readability.rs`.

**Shortcuts follow the layout.** `Keyboard::shortcut_code` maps a key to the US key of the Latin
letter the active layout puts there, so Ctrl+Z on a German keyboard is undo and Ctrl+A on AZERTY
selects all. Non-Latin layouts (Russian, Hebrew, Arabic, ...) keep the physical key. Shell applies
it while Ctrl is held, before browser commands and the clipboard keys; typing and compose still use
the physical key. Tests: `crates/sex-keymap/tests/layouts.rs`, `tests/app_input.rs`
(`actual_ctrl_shortcuts_follow_the_letter_on_the_key`).
