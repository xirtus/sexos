# Spreadeagle ODS AutoFilter (2026-11-25)

- **Change:** Preserve one AutoFilter per sheet in ODS `content.xml` with its exact database range, value and blank choices, paired comparisons, and Top/Bottom item or percent conditions. Rebuild imported filter state through GridCraft commands before clearing import undo so hidden rows and SUBTOTAL agree with the header controls.
- **Format:** ODF 1.3 [database ranges and filter conditions](https://docs.oasis-open.org/office/OpenDocument/v1.3/os/part3-schema/OpenDocument-v1.3-os-part3-schema.html) use `table:database-range`, `table:filter-and` / `table:filter-or`, and `table:filter-set-item`. Sheet names and absolute cell addresses are escaped when exported. A generated LibreOffice-format fixture covers a quoted sheet name, value set, and ranked filter.
- **Loss policy:** Unsupported ODF expressions produce an import warning instead of a false native filter. ODS export refuses conditions it cannot faithfully represent and directs the person to XLSX. Above/below average, colour/icon, regex, case-sensitive, and wildcard equality remain gaps.
- **Tests:** Focused host harness passed 10 ODS tests and 18 existing/new filter tests, plus the explicit unsupported-export check and generated LibreOffice-format fixture. Full build, QEMU, screenshot, and external LibreOffice interoperability remain GitHub CI or manual gates.
