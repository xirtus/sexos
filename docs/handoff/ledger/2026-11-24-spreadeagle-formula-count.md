# Spreadeagle formula count gate

The Spreadeagle host test now asks GridCraft's actual `formulas.functions` command for its catalog and requires at least 200 distinct names, including SUM, IF, XLOOKUP, FILTER and LET. This makes the requested breadth a continuing CI gate rather than an unverified claim. Calculation and file round-trip tests remain in the existing suite. No kernel, Wi-Fi driver, or tether changes.
