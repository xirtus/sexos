# Assuit: the word processor, on WordCraft's engine (workstream T1, second half)

**`apps/assuit`.** `run assuit NAME.docx` opens a document (docx, doc, odt, rtf, html, md, txt); a name that does not exist yet starts an empty document saved there. With no name it writes and opens `welcome.docx`.

- **Engine:** WordCraft's (github.com/storytold/wordcraft at a4b898f, MIT OR Apache-2.0), the ArtCraft suite's word processor. Its document model, Word-compatible layout, file formats, undo and every command run unchanged for `x86_64-sex-std.json`, and its renderer draws the pages with its bundled fonts (spelling underlines included). Size-optimised and stripped, the program is 27 MB; the program image is 32 MiB (`sex_pdx::program_store::IMAGE_BYTES`), so `scripts/install_program.py` and the store's refusal message now say 32 MiB.
- **Patches (reviewed with Andreas, listed in `scripts/check_tls_platform.py`):** `vendor/filetime-0.2.29` gains a Hermit-target module; `vendor/tar-0.4.46` treats the Hermit target like wasm32 (no unix paths, links or modes); `krilla` comes from storytold's craft-libs fork, as WordCraft's own workspace patches it. None touches TLS. sha2 0.10.9 is built with `force-soft-compact` for Assuit, because its unrolled SHA-256 holds WRPKRU bytes the loader refuses.
- **Window:** until egui runs on sex-app (M11), `apps/assuit/src/ui.rs` paints the caret's page centred on a grey desk, with the caret, a status line and zoom.
- **Keys:** WordCraft's (Word's) shortcuts through its own registry: arrows, Home/End, Ctrl+arrows, Shift to select, Enter, Backspace, Delete, Ctrl+B/I/U, Ctrl+Z/Y, Ctrl+A. Ctrl+S saves, Ctrl+=/-/0 zoom. A click places the caret; the wheel scrolls.
- **Tests:** `cargo test -p assuit` (host): opens the hand-written fixture (`apps/assuit/make_welcome.py`), draws ink, runs keys through WordCraft's commands, places the caret by click, and round-trips docx with text and pixels kept. `scripts/program_assuit_gate.py` (QEMU, in CI): open and draw, type, Shift+Home and Ctrl+B, Ctrl+S, close, reopen and find the edit.
- **Next:** pages around the caret's page (continuous scroll), selection highlight, open and save through Loom's picker, then the egui port of WordCraft's interface (ribbon, rulers, panes) once M11 lands.
