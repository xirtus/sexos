- 2026-11-19 WS3: self-wait source pins (timed-wait sources and kernel tree receipts) moved from tuples in scripts/check_self_wait.py to scripts/self_wait_pins.py, one pin per line with blank lines between, merged with `merge=union` (.gitattributes). Parallel kernel re-pins no longer conflict after long CI runs. Test: scripts/tests/test_self_wait_pins_merge.py.
- 2026-11-19 WS3: Display finishes a program row's reuse when the kernel already started the next run before Display's old-run cleanup committed (a late REBORN replay acked the dead run; the new run's REBORN was dropped). The row used to stall forever waiting for Display's ack: the Programs job hung on std spawn / Spreadeagle / Moan export reruns. Logged as `[display.app.reborn.ack] ... late=1 old_task=`.
- Files never drops a queued reply: `fs_service::reply_later` used to overwrite a pending reply to the same caller, so Shell's 500 ms settings poll could replace a program-load answer and leave a `chello` spawn waiting forever (master run 44565909758, Programs job). Replies now queue per caller in arrival order and are sent first-in first-out; a full queue logs `[files.fs.reply.lost]`.
