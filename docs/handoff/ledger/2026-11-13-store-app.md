## Store program and the `+pkg` run grant (2026-11-13, workstream I4, window side)

- **Grant**: `run +pkg NAME` (with `+net` in either order) lets that one run use package
  requests. Spindle adds the argument `+packages` to what it PREPAREs, so Files' binding
  of the run holds it; a program cannot add it (only Spindle prepares runs) and a typed
  `+packages` is dropped by Spindle. Files then lets the program use INSTALL, CHECK,
  REMOVE, LIST, CATALOG, SEARCH, LOCATE and SOURCE. TRUST and CONSENT stay Spindle's
  (they are the person's answers); INSTALL with `ALLOW_DOWNGRADE` is refused. Package
  paths are confined to the program's folder like its other paths, and CATALOG reads
  `download.catalog(.sig)` from that folder. Every refusal is DENIED and logged
  (`[files.pkg.denied] ... why=no_grant|downgrade|path|spindle_only|...`).
- **Store** (`apps/store`, sex-app window): the catalog (SEARCH), installed and newer
  marks, Up/Down, Enter installs or upgrades, Delete removes, R downloads the catalog
  again from the saved source (SOURCE), U upgrades everything (LOCATE), `/` narrows the
  list. Downloads go to its own folder with `sex_app::net`, then INSTALL; Files' report
  lines are its status text. Command mode for scripts: `store refresh | search WORDS |
  get NAME | upgrade | remove NAME` logs `[store.line]` and `[store.done] op= status=`
  and ends. Spindle `store [ARGS]` is `run +net +pkg store [ARGS]`.
- **sex-app**: `files::package(window, op, arg, length)` returns Files' status and the
  report, refused or not.
- **Grant question**: unchanged. A program the Store installed asks on its first run, in
  Spindle, as one installed by `pkg get`.
- **Gate**: `scripts/store_gate.py` (CI "Store program and the +pkg run grant"): without
  `+pkg` refused and nothing installed (also with a typed `+packages`), refresh, search,
  get, first-run question still asked (chello's own checks pass with the network denied), upgrade after
  the catalog offers 1.1, a second upgrade finds nothing, remove, and the window draws
  the list.
- ABI: programs may now send Files request kind 40 when their run holds `+packages`;
  new constant `sex_pdx::package::GRANT_TOKEN`. No syscall, no kernel change.
  `spec/abi_inputs.sha256` unchanged (`package.rs` is not an ABI input).
- Not yet: the Store does not show download progress or verify sizes before downloading;
  it cannot answer grant questions or trust publishers (by design, those stay Spindle's);
  the launcher does not list the Store yet.
