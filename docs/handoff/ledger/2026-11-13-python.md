# Python 3.13 (CPython) as an ordinary program (slice I9)

**`apps/python`.** CPython 3.13.18 now runs on SexOS as `run python ...`. The sources come from the `v3.13.18` tag of github.com/python/cpython and are vendored unmodified under `vendor/cpython-3.13.18`. They are under the PSF license, which is in `vendor/cpython-3.13.18/LICENSE`. Only the 562 files the build compiles or includes are vendored (Include/, and parts of Objects/, Python/, Parser/ and Modules/, about 16 MB). The list was taken from `clang -M`.

The app builds the way `apps/lua` builds Lua. `build.rs` compiles about 200 C files with clang against musl's headers, in parallel, into `libpython.a`, and `src/main.rs` hands `argv` to `sex_libc::posix::run`. There is no configure run. Three files in `apps/python/port/` take its place:
- `pyconfig.h`, written by hand. It started from what configure finds for static x86-64 musl and was cut down to what sex-libc provides. pymalloc is on, and with no `mmap` its arenas come from `malloc`. `_Thread_local` uses the target's local-exec TLS.
- `config.c`, the built-in module table:
  - posix, errno, _io, _codecs, _weakref, _abc, _functools, _collections, itertools, _operator, _signal, _stat, _thread
  - time, atexit, faulthandler, _tracemalloc, _suggestions, _sre, _sysconfig, _typing, _symtable, _opcode
  - math, cmath, _struct, _random, _json, _bisect, _heapq, binascii, array, _datetime, _contextvars, _queue, _statistics, _sha2 (HACL*)
  - the interpreter's own modules: marshal, _imp, _ast, _tokenize, gc, _warnings, _string
- `sexos_main.c`. It holds:
  - `sex_python_main`: pre-initialises in UTF-8 mode, installs no signal handlers, then runs `Py_RunMain` with the ordinary command line. `-c`, scripts, `-m` and the REPL all work as usual.
  - `_PyConfig_InitPathConfig`, which replaces `Modules/getpath.c` and its frozen `getpath.py`. The prefix is `/`, which is the program's own folder, `/data/python`. `sys.path` is the script's directory, then `/lib`. `/lib` is where extra pure-Python modules can be put.
  - It sets `TERM=dumb` and `PYTHON_BASIC_REPL=1` unless they are already set. A program's window interprets no escape sequences, so tracebacks come without colour and the line-by-line REPL is used.

**The standard library is frozen into the binary**, so nothing has to be installed in the program's folder:
- `scripts/python_freeze.py` (run with python3.13) compiles 84 modules from a CPython checkout's `Lib/`. They are marshalled to `apps/python/frozen/*.bin`, 2.4 MB in all, and listed in `MANIFEST`.
- `build.rs` turns that folder into CPython's frozen-module tables (the role `Python/frozen.c` has upstream). An assembler file `.incbin`s the bytes.
- The set covers:
  - importlib's bootstrap and zipimport
  - startup: encodings (utf_8, utf_8_sig, ascii, latin_1, aliases), site, os, posixpath, stat, io, abc, codecs
  - traceback and everyday modules: json, re, enum, functools, collections, dataclasses, datetime, decimal (`_pydecimal`), fractions, statistics, random, typing, argparse, textwrap, string, pprint, inspect, dis, ast, tokenize, copy, heapq, bisect, base64, struct, shlex, glob, fnmatch, calendar, difflib, gettext, locale, runpy and more
- Bytecode belongs to one release series, so re-freeze with 3.13 after any change to the module list.

The binary is 7.5 MB. The program store's limit is 16 MB.

**Registration** (one line or stanza in each list):
- the workspace `Cargo.toml` and `Cargo.lock`
- `sexos_build_spec.toml`: the whitelist entry and the `build_python` stage, which writes `iso_root/programs/python`

**`crates/sex-libc` additions** (userspace C library only, with no kernel or service change):
- `<wchar.h>`: `wcscmp`, `wcsncmp`, `wcscpy`, `wcsncpy`, `wcschr`, `wcsrchr`, `wcstok`, `wcstol`, `mbstowcs`, `wcstombs`. A host test was added.
- `nl_langinfo`: `CODESET` is "UTF-8" and `RADIXCHAR` is ".".
- An environment that the program itself can change:
  - `setenv` and `unsetenv`
  - `getenv`, which reads that environment
  - `environ`, which starts empty as before
- `sysconf`, which is now exported on the ordinary-program target too, and answers `_SC_CLK_TCK` (100).
- `acosh`, `asinh` and `atanh` (and their `f`/`l` forms).
- `clock_getres` (1 ms), `times` (the program's running time, in 10 ms ticks), and `timegm` (which is `mktime`, because local time is UTC).
- On the ordinary-program target (`posix.rs`):
  - `getrandom` and `getentropy`, over sex-std's `sys_read_entropy` (RDRAND). They seed hash randomisation, `os.urandom` and `random`.
  - `dup2`: it works when the duplicate lands on the closed number, and otherwise fails with EBUSY.
  - `utime` and `pause` fail with ENOSYS.
  - `__libc_current_sigrtmin` and `__libc_current_sigrtmax` (35 and 64).

**Gate** (`scripts/python_gate.py`, CI step "Python 3.13 interpreter (CPython)" after the Lua step). It installs `python` onto a blank disk and types six runs into Spindle, using lua_gate's echo-confirmed typer:
1. `-c print(2**100)` must print `1267650600228229401496703205376`.
2. A chunk with dict, list and set comprehensions, f-string format specs, `%` formatting, `map` and `join`.
3. `json.dumps(..., sort_keys=True)`, `json.loads` and `re.sub`.
4. A chunk that writes the script `t.py` with `open`, then reads it back.
5. `run python t.py x y`: `sys.argv`, `os.listdir('.')`, and `time.time()`, which must be within 10 minutes of the host's clock.
6. `json.loads('{bad')`: the traceback must reach `[std.err]` with no escape sequences, ending in `json.decoder.JSONDecodeError: ...`, and the exit status must be 1.

**What doesn't work, and why:**
- There are no processes, so `subprocess`, `os.fork`, `os.exec*`, `os.system` and `os.kill` are absent or fail. `posix` is built with only what sex-libc provides.
- There is no signal delivery, so Ctrl-C does not raise `KeyboardInterrupt`, and `signal.pause()` fails with ENOSYS.
- There are no C extension modules (no `dlopen`), so only the built-in modules above are available.
- These are not built yet:
  - `socket`, `select` and `ssl`: sex-libc has BSD sockets, so `socket`/`select` could come next.
  - `zlib`, `_hashlib`, `_md5`, `_sha1`, `_sha3`, `_blake2`, `unicodedata`, `_decimal` (`decimal` uses `_pydecimal`), `_pickle`, `_csv`, `_locale`, `mmap`, `termios`, `pwd` and `grp`.
- The frozen set is fixed. Other pure-Python stdlib modules (`pathlib`, `logging`, `unittest`, `pickle`, `subprocess`...) are not frozen yet. They can be copied as `.py` files into the program folder's `lib/`. Or add them to `MODULES` in `scripts/python_freeze.py` and re-freeze.
- Tracebacks show no source lines for frozen modules, because the `.py` files are not on disk. This is upstream's behaviour for frozen modules.
- `os.utime` fails with ENOSYS, because file times are kept by the store.
- `dup2` only works onto the lowest free descriptor.
- Local time is UTC, as everywhere in sex-libc.
- The REPL is the basic one (`PYTHON_BASIC_REPL`). The new full-screen REPL needs escape sequences and termios.
