# Spreadeagle ODS charts (2026-11-25)

- **Change:** Write clustered column and line charts as embedded ODF chart objects with live data and category ranges, series labels, title, legend, and physical sheet position. Restore those objects into GridCraft when opening ODS. ODF 1.3 chart objects use `draw:frame` / `draw:object`, a chart `content.xml`, and manifest entries; category ranges belong inside the x-axis ([ODF 1.3 schema](https://docs.oasis-open.org/office/OpenDocument/v1.3/os/part3-schema/OpenDocument-v1.3-os-part3-schema.html)).
- **Loss policy:** ODS export refuses chart types and options outside this subset and suggests XLSX. Import warns for source styles and axes that may differ; when an embedded chart cannot be restored, it warns and refuses an ODS overwrite. The original file remains available for review. Horizontal bars, pie, doughnut, stacked, secondary axes, custom colors, data labels, data tables, and chart-specific advanced formatting remain open.
- **Evidence:** Three focused host tests cover column and line object round trip through the package and Book open, LibreOffice re-save interoperability from `apps/spreadeagle/assets/lo-charts.ods`, and refusal of unsupported pie export. LibreOffice retained both chart objects, category links, and positions after re-save. The feature-specific GitHub CI QEMU gate opens the fixture and captures `spreadeagle-ods-charts.ppm`. Full build and QEMU verification are CI-only and pending.
