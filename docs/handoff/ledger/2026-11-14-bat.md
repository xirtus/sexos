# bat as an ordinary program (slice I7, last item)

**`apps/bat`.** bat 0.26.1 runs on SexOS as `run bat ...`. It is the upstream program, not a rewrite: the binary source is vendored from the crates.io package (`bat-0.26.1.crate`) and builds on the published `bat` library, with syntect's pure-Rust regex engine (`regex-fancy`, i.e. fancy-regex) instead of Oniguruma. No C: `git` (libgit2), `paging` (less or the minus pager) and `lessopen` stay off. The app crate is a `Cargo.toml` whose `[[bin]]` points at the vendored `main.rs`, plus the 8 MiB-stack `build.rs`; its package is `bat-app` so it is not confused with the `bat` library.

- `vendor/bat-0.26.1/`: `src/bin/bat` (the binary source), `assets/theme_preview.rs` (included by it) and the licence files (MIT OR Apache-2.0). Syntaxes and themes come from the library's built-in assets.

Three library crates did not build for `x86_64-sex-std.json` (os = "hermit"); each is vendored and patched (`[patch.crates-io]` in the workspace `Cargo.toml`, listed as reviewed in `scripts/check_tls_platform.py`), changes marked `SexOS:`:

- `console` 0.16.6: only unix, windows and wasm had a terminal backend. Hermit now uses the wasm stand-in (no size query, no raw keys), so bat's width is console's default of 80 columns.
- `path_abs` 0.5.1: `symlink_dir`/`symlink_file` existed only for unix, windows and wasi. On Hermit they return Unsupported (SexOS has no symbolic links; bat never makes one).
- `clircle` 0.6.1: `compile_error!` off unix/windows. On Hermit no file can be identified, so bat never sees an input/output circle (as on Windows for its terminal).

SexOS changes in the vendored binary source, each marked `// SexOS:`:

- `main.rs`: `use sex_std as _;`. Without the `paging` feature the library has no `PagingMode`, `OutputType::from_mode` or `Config::paging_mode`, which the binary used unconditionally; a local `PagingMode` keeps bat's own option logic (`-p`, `-pp`, `--paging`) and output always goes to standard output (`--list-themes` writes there directly; the terminal title, only set when paging, is never set).
- `app.rs`: the same paging fields out of `Config`. Whether standard output is a terminal comes from `sex_std::sys::sys_isatty(1)`: std's Hermit port answers `is_terminal` with false for every stream (hermit-abi's placeholder `isatty`), which made bat behave as `cat`. Standard output is the program's window, a console a person reads, so bat keeps its decorations (header, grid, line numbers) and wraps. Colour on `auto` only when `TERM` is set and not `dumb` off unix/windows, as for fd: the window shows no ANSI colours.
- `main.rs` again: errors go through a handler that writes `[bat error]: ...` plain when the terminal shows no colours (the library's own handler always paints it red).
- `directories.rs`: there is no home folder (std's Hermit `home_dir` is None, and bat panicked "Could not get home directory"); configuration and cache are `config` and `cache` in the program's own folder unless `BAT_CONFIG_DIR`/`BAT_CACHE_PATH` say otherwise.
- `clap_app.rs`: the command is named `bat` (it was the package name, now `bat-app`).

**Registration** (append-only): workspace `Cargo.toml` members and three patches; `sexos_build_spec.toml` whitelist entry and the `build_bat` stage (`iso_root/programs/bat`); `Cargo.lock` gains the new packages (no existing version moved). Size: bat 5.3 MB (5,344,192 bytes; program store limit 16 MB).

**Gate** (`scripts/bat_gate.py`, CI step "bat" after "ripgrep and fd"). Typed into Spindle as in `rg_fd_gate.py`:
1. `run bat --version` prints `bat 0.26.1`; Files makes `/data/bat`.
2. Spindle's `write`/`append` make `hello.rs` (three lines of Rust).
3. `run bat hello.rs`: a header line `File: hello.rs` and lines 1 to 3 numbered in bat's grid; no escape sequences anywhere.
4. `run bat --list-languages` has a `Rust` line listing `rs`.
5. `run bat -p hello.rs` prints exactly the three lines.
6. `run bat missing.rs` prints `[bat error]: ...missing.rs...` on standard error and exits 1.

**What doesn't work, and why:**
- No pager (`--paging`, `--pager` are accepted and ignored): a pager is another program and `std::process::Command` is Unsupported; the window keeps the newest lines.
- No git change markers (`--diff`, the `changes` style): libgit2 is C.
- No colours by default: the window does not interpret ANSI. `--color always` still emits escapes; `bat --list-themes` therefore lists names without previews. The rare `[bat warning]` (from the library) is still painted yellow.
- Width is 80 columns whatever the window's size (console cannot ask the window).
- `bat cache --build` is not built in (`build-assets` off); custom syntaxes/themes from a `cache` folder made elsewhere still load.
- `--diagnostic` reports that bat was built without `bugreport`; no shell completions (`application` off).
- Ctrl-C does not stop it (no signals); closing the window does.
