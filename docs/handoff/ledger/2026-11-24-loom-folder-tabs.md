# Loom folder tabs, 2026-11-24

Add up to twelve folder tabs with independent paths, selection and scroll
position. A tab may be opened, switched or closed while browsing an ordinary
folder. During a picker question, background job, search, archive, image or
remote place view, tab changes wait until that operation or view ends.

The Loom QEMU gate opens a second tab, enters a folder, switches back and
forth, closes the second tab and captures `folder-tabs.ppm`. The existing
archive, batch rename, trash and preview checks continue in GitHub CI.
