# 2026-11-26 — Alienware x17 R1 USB UVC Webcam (`0c45:6d18` → `sexuvc`) Bring-Up

## Scope
Wired the Alienware x17 R1's USB UVC webcam (`0c45:6d18`, detected by `sexusb` as MJPEG & YUY2 `1280x720`, `control=0`, `stream=1`, `alts=6`, `max_payload=3072`) end-to-end from `servers/sexusb` to `servers/sexuvc` while keeping the QEMU `SyntheticUvcDevice` fallback and 512 MiB memory budget intact.

## Changes
1. **Shared Memory Protocol (`crates/sex-pdx/src/usb_uvc.rs`, `crates/sex-pdx/src/lib.rs`)**:
   - Added `sex_pdx::usb_uvc` (128 KiB shared region at `SLOT = 1010`, `NOTIFY_SLOT = 1011`, `REGION_ID = 0x4407`, `SEXUVC_PD = 55`, `SEXUVC_KEY = 4` (Senses organ), `OP_LINK = 0x2CC`).
   - Header carries attached camera metadata (`vendor`, `product`, `control_iface`, `stream_iface`, `alt_count`, `bulk`, `max_payload`, up to 6 `FormatMeta` entries), `CMD_START`/`CMD_STOP` command/ack handshake, stream state, and counters.
   - 30 × 4 KiB chunk ring (`MAX_CHUNK = 4088`, flags `FLAG_SOF | FLAG_EOF | FLAG_ERR | FLAG_FID`, monotonic `frame_seq`) streams arbitrarily large frames (both MJPEG and YUY2) inside a compact 128 KiB footprint.

2. **Kernel & Boot Wiring (`limine.cfg`, `kernel/src/boot_memory.rs`, `kernel/src/init.rs`)**:
   - Added `MODULE_PATH=boot:///servers/sexuvc` to all boot entries in `limine.cfg`.
   - Added `boot_memory::init_usb_uvc(usb, uvc)` pairing the 128 KiB `usb_uvc` region and granting `NOTIFY_SLOT` from `sexusb` to `sexuvc`.
   - Factored optional boot server spawns (`denim`, `cufflinks`, `sexuvc`, `saddle`, `sexgpu-nv`) via a compact `spawn_opt` helper in `kernel/src/init.rs` and added `55 => "sexuvc"` to the handoff name table. Net kernel non-blank line count **decreased** from 24,500 to 24,480 (under the 24,500 budget).

3. **USB UVC Streaming Transport (`servers/sexusb/src/uvc_stream.rs`, `servers/sexusb/src/uvc.rs`, `usb.rs`, `main.rs`)**:
   - Added pure `#![no_std]` zero-alloc `uvc_stream.rs` for 2–12 byte UVC payload header stripping (FID toggle, EOF, PTS/SCR, ERR-bit frame drop), chunked frame reassembly, and 26-byte `VS_PROBE`/`VS_COMMIT` wire encoding/decoding.
   - Added `servers/sexusb/src/uvc.rs`: publishes detected UVC webcams into `sex_pdx::usb_uvc::Shared`, sends `OP_LINK`, handles `CMD_START`/`CMD_STOP` (`VS_PROBE` SET_CUR/GET_CUR, `VS_COMMIT` SET_CUR, `isoch::pick_alt`, xHCI Isoch/Bulk IN endpoint configuration with CErr=0 and burst/mult/ESIT parameters, `SET_INTERFACE`, and lazy DMA buffer allocation), strips UVC headers on transfer completion events, and pushes chunks into the ring.

4. **Userspace Driver (`servers/sexuvc/src/main.rs`)**:
   - Opens `sex_pdx::usb_uvc::SLOT`, logs `[sexuvc.transport]`, and replies `0` to `OP_LINK`.
   - When a physical USB camera is published by `sexusb` (at boot or hot-plugged), logs `[sexuvc.usb.attached] vendor=... product=... max=...`, selects the preferred format (MJPEG → YUY2 → first), issues `CMD_START`, and pumps real frame chunks from the shared ring (`[sexuvc.frame] source=usb ...`).
   - When no physical USB camera is attached (e.g. QEMU), preserves the existing `SyntheticUvcDevice` startup path untouched so all existing QEMU/camera gates remain green.

5. **Tests & ABI Pins (`tests/sexusb_uvc.rs`, `spec/abi_inputs.sha256`)**:
   - Added `tests/sexusb_uvc.rs` covering 2–12 byte header stripping, FID toggle, EOF/multi-chunk reassembly, error-bit drop & recovery, `VS_PROBE`/`VS_COMMIT` wire format, and end-to-end `sexusb <-> sexuvc` ring handoff.
   - Re-pinned `spec/abi_inputs.sha256` via `scripts/update_abi_hashes.sh`.
