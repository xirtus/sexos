# Valentine keyboard reference

The native mail window now opens an offline keyboard reference with
Ctrl+Shift+/. It lists the controls currently delivered to Valentine and
keeps a draft intact while the reference is open. The reference and its
documentation show only Valentine and SexOS names.

The existing Valentine QEMU gate opens and closes the reference, checks its
serial state, and captures `valentine-shortcuts.ppm`. Full build and QEMU
verification run only on GitHub CI.
