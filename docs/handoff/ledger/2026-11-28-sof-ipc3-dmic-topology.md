# 2026-11-28: `sex-sof` stage 2: SOF IPC3 messages + fixed DMIC capture graph

- `crates/sex-sof/src/ipc3.rs`: SOF IPC3 (Tiger Lake's default firmware ABI) as plain bytes. ABI 3.23.1 (Linux `include/uapi/sound/sof/abi.h`); firmware is accepted when the major number is 3. Has the global and command constants (reply, compound, topology, PM, component, stream, DAI, FW_READY, trace). Encoders write into a caller `&mut [u8]` and return the length, so nothing allocates: buffer/host/DAI component new (with an optional component UUID), pipeline new/complete/free, comp connect/free, DMIC `DAI_CONFIG`, `STREAM_PCM_PARAMS`, trigger start/stop, PCM free, PM core enable/gate/context save. Decoders: the generic reply, the PCM params reply (position offset), the stream position, and FW_READY (version, build, date/time/tag, ABI, flags) with an extended-data walk and the window list. The window list maps to inbox/outbox/stream/debug offsets and sizes in the DSP BAR.
- `crates/sex-sof/src/topology.rs`: `DmicCapture::TGL_DEFAULT` is DMIC DAI 0 -> buffer -> host PCM capture, 48 kHz, 2 ch, S32_LE. `start_steps()`/`stop_steps()` give the message order and `encode_start(n, buf)`/`encode_stop(n, buf)` write step `n`. Pipeline-first order for firmware ABI >= 3.19, pipeline-last for older (`for_firmware_abi`). `encode_page_table` is Linux `snd_sof_create_page_table` (20-bit frame numbers, two per 5 bytes).
- Where the values come from: `sof-tplg/sof-hda-generic-2ch.tplg` in the sof-bin `v2026.09.2` release tarball (tplg sha256 `7896ab52853e64d063f5e897011d200c2944732d75a96787667454fe2f443c53`), decoded from the binary. Pipeline 10 (`PIPELINE.10.DMIC0.IN`): period 1000 us, priority 0, core 0, frames 0, MIPS 5000, timer time domain, dynamic. Buffers are 768 B with caps 113. Host `PCM6C` has sink/source periods 0/2. DAI `DMIC0.IN` has index 0, periods 2/0, s32le. Link `dmic01`: driver v1, pdmclk 2.4–4.8 MHz, duty 40–60 %, fifo 48000 Hz/32 bit, unmute ramp 200 ms, 1 PDM active, PDM0 with mic A + mic B, hw_config fmt 0. The tplg's EQIIR high-pass and `Dmic0` volume stages are left out because they need coefficient and gain data first.
- Struct sizes and offsets were measured by compiling Linux `include/sound/sof/*.h`. Message contents follow `sound/soc/sof/ipc3-topology.c` and `ipc3-pcm.c`.
- Tests: `tests/ipc3_layout.rs` (every encoder byte-exact: sizes, key offsets, zeroed reserved fields, short buffers refused; reply/PCM reply/position decode), `tests/ipc3_fw_ready.rs` (hand-built FW_READY + CC-info + window records -> version strings, ABI, mailbox layout), `tests/topology_dmic.rs` (tplg defaults, full start/stop order and bytes, custom ids, page-table packing against the Linux store pattern). `scripts/sof_host_gate.sh` passes.
- No runtime change. Bell starts using this in stage 4.
