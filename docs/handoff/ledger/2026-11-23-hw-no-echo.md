# 2026-11-23 `hw` skips its own echoes; `wifi` names the join step

- Spindle `hw` echoes the lines it shows as `[spindle.hw.line]` (scripts/nvme_real_drive_gate.py
  reads them); a later `hw` now skips those copies, so on the x17 R1 it shows the real
  lines, not earlier runs' echoes.
- `wifi` while connecting says which step it is on: 1 restarting the chip and looking for
  the network (retries ~3 min), 2 tuning to its channel, 3 association, 4 WPA handshake.
  A stalled join on the x17 showed only "connecting to the network".
- A 2 MiB log ring was tried first: it cost 2 MiB of kernel memory and the 512 MiB
  Kodi gate ran out of program frames, so the ring stays 64 KiB.
