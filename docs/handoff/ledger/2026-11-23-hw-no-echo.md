# 2026-11-23 Spindle `hw` stops echoing its lines into the log it reads

- `hw` wrote every shown line back to the kernel log as `[spindle.hw.line]`, so each run
  filled the newest 64 KiB (`OP_LOG_TAIL`) with copies. On the x17 R1 the photos showed
  only those copies and `hw wifi.join` found nothing. The echo is gone.
- A 2 MiB ring was tried first: it cost 2 MiB of kernel memory and the 512 MiB
  Kodi gate ran out of program frames, so the ring stays 64 KiB.
