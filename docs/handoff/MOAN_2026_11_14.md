# Moan, round 171: timeline and mixer engine

Moan is the planned audio workstation. This first slice is `crates/moan-core`, a
GPL-3-only, no_std + alloc engine, and `apps/moan-probe`, a guest proof program.
There is no DAW window yet: the shared Weft toolkit is in open PR #220.

## Engine contract

- Immutable borrowed stereo i16 sources, all at 48 kHz. Positions and lengths are
  frames, not samples or milliseconds. Convert other rates before insertion.
- Non-destructive split and trim. Trim keeps the retained audio's timeline position
  and removes fades. Split preserves outer fades, clamped to each new clip length,
  and leaves the new inner edges unfaded. This can change an envelope crossing the
  cut; it is explicitly not a promise to preserve a faded split's waveform.
- Clip gain and track volume, each 0..400%; linear stereo balance -100..100,
  centre unity. Mute and solo; muted solo tracks do not suppress other tracks.
- Overlapping clips sum. Render fills a caller-owned block without allocating,
  accumulates before PCM clipping and returns silence outside clips. Block size
  does not change output. Source memory remains the caller's responsibility.
- Linear fades include a silent endpoint and reach unity at frame length-1. A
  one-frame fade is silent. Overlapping fade-in/out envelopes multiply.

## Round 172: per-track effects

`effects::Rack` holds optional EQ, compressor and reverb in that order. An empty
rack bypasses samples exactly. Configuration allocates only when creating reverb
(about 124 KiB); processing and reset do not allocate. All DSP uses bounded integer
arithmetic, at 48 kHz, with headroom before final PCM clipping.

- EQ: three bands, nominal 200/4000 Hz one-pole crossovers, 0..400% per band.
  Residual bands make flat unity gains reconstruct the original signal exactly.
- Compressor: stereo-linked peak detector, threshold 1..32767, ratio 1..20,
  attack/release smoothing divisors 1..480000 frames. No lookahead, makeup gain or
  soft knee; slow attacks intentionally pass transients. Ratio 1 bypasses gain.
- Reverb: four parallel feedback combs and two serial allpasses, fixed delay lengths,
  feedback 0..90%, wet 0..100% added to dry. It is a small algorithmic reverb, not
  convolution or a model of a particular room.

`render` remains the stateless dry renderer. `render_processed` runs each track's
rack before its volume and pan. Render sequential blocks to preserve history;
pausing makes no calls. A discontinuous playhead resets all racks, while an empty
render changes nothing. Muted/non-solo tracks advance DSP without entering the mix.
Continue rendering beyond clip ends to drain tails; call `Track::reset_effects`
after edits or project changes when tails should be discarded. Standalone rack
processing requires the caller to reset when starting a new stream.

There are 21 host integration tests. `scripts/moan_host_gate.sh` also renders a
reference WAV on the host and qualifies the effects waveform checker against it.
`moan-probe fx` in QEMU plays one second of compressed signal followed by silence;
`scripts/moan_gate.py --effects` checks stereo pitch, the lower peak, a nonzero
reverb tail after source audio ends, and decay. The host reference is not evidence
of guest playback; that claim still requires the QEMU gate to pass in CI.

## Round 177: Moan's Weft app

`run moan` now opens a real Weft window. Add overlapping tracks with Tone, import
48 kHz stereo signed-16-bit PCM WAV, or Record from the existing Bell microphone
ring. Play/Pause/Stop use that same program sound ring. Capture waits for the
existing microphone grant, reports an absent microphone, preserves dropped frames
as silence, drains pending capture before Stop, and caps each take at 60 seconds.
Up to eight tracks are supported. Empty tracks remain selectable.

The clip timeline table shows track/clip, start, end and gain. Select a track, set
the playhead/range in seconds, then split at the playhead, cut the selected range,
fade clip edges or change gain. Track volume, stereo balance, mute, solo and three
effect presets are standard Weft controls. Undo/redo retain twelve edit snapshots
using shared immutable PCM; edits are disabled during active or paused transport.

Export WAV asks Files for a destination, exclusively creates a new file, streams
the processed mix plus two seconds of effect tail, and reports success only after
sync. Failed output remains named and partial. Import/export use held Files routes
and the shared picker. This initial app's PCM WAV writer is native Rust; FFmpeg
FLAC/MP3 export is still outstanding. The current FFmpeg build only enables audio
decoders, so enabling actual encoders is a separate port change, not an extension
rename. No project save format or graphical waveform editor is claimed yet.

Validation: 21 engine/effect tests plus eight app/project/UI tests; a guest release
build and key-instruction scan. The host window is rendered by the same Weft tree
for visual QA. `scripts/moan_app_gate.py` performs real guest pointer-created tracks,
playback verified in QEMU's WAV, split/undo, a nonblank screenshot and close. Its
`--microphone` pass additionally requires the existing user grant before captured
frames become a third track. Both passes are in CI; runtime validation remains
pending until those gates pass. This branch depends on Weft #220 and Moan #244/#246.

## Round 180: editable project persistence and waveform timeline

Moan now saves self-contained editable `.moan` projects, separately from exported
mixdowns. Save Project (`Ctrl+S`) asks the existing Files picker for a new filename,
uses exclusive CREATE, streams bounded writes and synchronizes before marking the
session clean. Existing files are never overwritten. A failed save retains its
named partial output and keeps the session unsaved. Open Project (`Ctrl+Shift+O`)
replaces the session only after a complete bounded decode; invalid data, picker
cancellation and short reads keep the current work intact. The Shell may also
launch a held project route (`run moan @/edit.moan`), which uses the same decoder.

New Project (`Ctrl+N`), Open and Quit use a standard Weft Cancel/Discard dialog for
unsaved work; Cancel is the default. Closing during export or project I/O cancels
that output and preserves partial output without bypassing the project guard.
An active microphone recording also requires confirmation even before its first
frames have been appended to a track. Export-error cleanup attempts to sync the
partial output and records whether it succeeded, without claiming successful
finalization. Undo/redo revisions retain a saved baseline: reopening starts clean,
with empty history, and undoing the first edit returns to the loaded clean state.

The waveform timeline is audio document content inside a Weft image. It displays
clip boundaries, combined stereo extrema without opposite-polarity cancellation,
clip gain/fades, the selected time range and playhead. The toolkit still owns all
buttons, sliders, menus, dialogs, layout, scrolling and focus. `Ctrl+T` scrolls to
Show Waveform Timeline. Drag a track row to select a time range, then Cut Selected
Time (`Ctrl+Shift+K`), or place the playhead and Split Clip (`Ctrl+E`). Enable the
standard Drag Clips checkbox (`Ctrl+Shift+M`) to move a clip; one complete drag is
one undoable edit and shares immutable source PCM. Pointer coordinates and range
ends are clamped to the view/timeline; active transport and overlay menus/dialogs
keep input ownership. Zoom, fit and earlier/later controls adjust the visible range.
The retained content uses a bounded Weft scroll viewport at the initial 640×400.

The export format buttons and `Ctrl+Shift+1/2/3` select WAV/FLAC/MP3; the export
button reads Export Audio. Actual encoding is the coordinated round 181 workstream.

### Project v1 format and bounds

- Little-endian 64-byte header: `MOANPRJ\0`, version 1, zero flags, 48 kHz rate,
  exact file size, FNV-1a corruption checksum (all bytes except the checksum field),
  source/track counts, selected track, and frame positions for playhead/selection.
- Source table: each immutable stereo i16 PCM source is stored once. Split and cut
  clips reference source IDs plus source offset/length, preserving editability.
- Tracks store volume, pan, mute/solo, optional EQ gains/compressor parameters/
  reverb parameters, and clip start/gain/fade lengths. DSP delay/envelope history
  is reset on reopen; transient DSP state, undo history and zoom are not serialized.
- Maximum 96 MiB file, eight tracks, 1,024 clips/sources, one minute per source,
  eight minutes total unique PCM, and 3,660 seconds of timeline. Counts, ranges,
  offsets, flags, effect controls and exact/trailing lengths are checked before
  PCM allocation. Unused sources and nonzero reserved fields are rejected.
- The checksum detects accidental corruption; this is not authenticated encryption.
  Decode failure never partially mutates an existing Session.

There are 28 Moan host tests covering existing edits, codec round trips/shared IDs,
malformed/truncated files, atomic open, active DSP equivalence, saved undo baseline,
actual pointer cut/move, opposite-polarity audio, 640×400 access, real format keys,
modal ownership and unsaved confirmation. The actual guest builds with the pinned
FFmpeg profile and passes the instruction scan. `scripts/moan_project_gate.py`
selects/cuts waveform audio, saves through Files, reboots, reopens the exact saved
hash through a Shell-held route, edits/undos to the loaded clean baseline and keeps
waveform screenshots. QEMU runtime evidence remains pending until CI executes it;
a host render or successful compile does not establish those guest results.
