# egui on SexOS (slice M11, first part) — 2026-11-14

`crates/sex-egui` runs ordinary egui 0.37 code in a SexOS program window. It is for
porting egui apps (the ArtCraft "Craft" apps for Gingham, Brocade, Batik, Gestalt and
friends); Weft (`crates/weft`) stays the toolkit for SexOS's own apps.

## Writing or porting a program

1. Build it for `x86_64-sex-std.json` with `build_std = "std,panic_abort"` (a stage in
   `sexos_build_spec.toml`, like `build_tassel`). Rust `std` comes from `crates/sex-std`.
2. Depend on `sex-egui` and `egui = "0.37"`.
3. Replace `eframe::run_native` / `run_simple_native` with:

   ```rust
   sex_egui::run_ui(sex_egui::Options::new("Title"), move |ui| app.ui(ui));
   // or, for code written against &egui::Context (panels, windows):
   sex_egui::run_ctx(sex_egui::Options::new("Title"), move |ctx| app.update(ctx));
   ```

4. Images: call `egui_extras::install_image_loaders(ctx)` once (features `svg`, `image`),
   as Tassel does.

## What works

- Keys with Shift and Ctrl, the text the person's keyboard layout or input method typed
  (so `ü`, dead keys, Compose and Pinyin reach text fields), every egui shortcut.
- Mouse moves, left/middle/right buttons, wheel scrolling.
- Copy, cut and paste between egui text fields of the program (Ctrl+C/X/V).
- HiDPI: `--scale=2` on the command line or `Options::scale`; Ctrl+Plus/Minus zoom.
- Repaints only on input or when egui animates; an idle window costs nothing.
- egui's own demo (`egui_demo_lib`) runs unmodified: `run tassel`.

## Not yet

- The Shell clipboard (other programs): needs a clipboard grant for ordinary programs.
- Alt and key releases: Shell sends presses with Shift/Ctrl only; each press becomes a
  press and release for egui. Alt shortcuts and games that hold keys need key-up events.
- Cursor shapes, IME preedit display, multiple windows (egui viewports), file drops.
- GPU painting (sex-gl) and partial repaints: the CPU rasterizer redraws the frame.
  egui's demo at 1280x800 is about 48 ms a frame on the host in release.
- craft-libs shims (`craft-window`, `craft-update` off, `craft-print` → Needle): with
  the first Craft port, in the office thread.

## Proof

- `cargo test -p sex-egui`: key and pointer mapping, rasterizer (top-left rule, blending,
  clipping, scale, textures), whole frames: a click clicks a button, typing fills a field
  (including a layout-only character), copy/paste between fields, the demo paints.
- `cargo run -p sex-egui --example screenshot -- out.png 1280 800 1`: the demo as a PNG.
- `scripts/program_egui_gate.py` (CI runtime job): `run tassel probe` takes clicks, keys,
  a checkbox toggle and wheel scrolling, read back from its serial record; `run tassel`
  paints egui's demo and is screenshotted.
