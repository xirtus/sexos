# Weft: the SexOS UI toolkit (workstream M)

Weft (`crates/weft`) is the toolkit native SexOS programs build their windows with. It
is `no_std` + `alloc`, so it runs in plain SexOS programs (`x86_64-sex-app`) and in
ordinary Rust `std` programs alike. Abacus (`apps/abacus`), the calculator, is the first
program on it.

## What it does

| Piece | Where | Notes |
|---|---|---|
| Layout | `ui.rs`, `widget.rs` | taffy 0.15 flexbox, grid and block. `Layout` builder; per-kind defaults. |
| Painting | `paint.rs`, `draw.rs` | tiny-skia shapes, sex-font text, clip stack. Repaints only damaged rectangles (layout diffs each widget's rectangle). |
| Text | `text.rs`, `edit.rs` | Geist Sans and Mono (Noto fallbacks behind `fallback-fonts`), wrapping, a line editor with word moves, selection and undo. |
| Widgets | `build.rs` | panels, cards, scroll views, splits, labels, paragraphs, buttons (normal, primary, flat, danger, icon), fields, password fields, check boxes, switches, radio groups, sliders, progress (and busy) bars, icons, images, separators, lists, tables and trees over any `ListModel` (only visible rows are asked for: a million rows cost the same as ten), tab strips, menu bars. |
| Keyboard | `events.rs` | Tab/Shift+Tab, arrows, Space/Enter, Escape, F10, Shift+F10/Menu key, Ctrl+Shift+P, type-to-find in lists, Ctrl+A/C/X/V/Z/Y in fields. |
| Pointer | `events.rs` | hover, press, double/triple click, drags for sliders, split dividers, scroll bars, list selection, field selection and tabs; wheel scrolling; right-click context menus; middle-click closes a tab. |
| Commands | `menu.rs` | One `Command` per action (label, shortcut, icon, keywords, checked); menus, the palette and shortcuts all read it. Keymap text rebinds (`app.copy = Ctrl+Shift+C`). |
| Overlays | `overlays.rs` | menu bar and context menus with submenus, the command palette (fuzzy search), dialogs (message, confirm, save changes, prompt, colour, font), toasts with an action, tooltips. |
| Document tabs | `build.rs`, `events.rs` | `document_tabs`: closable, New Tab button, pinned tabs (icon only, kept first), groups (coloured line), modified dot, reorder by drag, tear-off (`TabEvent::TornOff` with the drop point), Ctrl+Tab, Ctrl+Shift+Tab, Ctrl+W, Ctrl+T, Ctrl+1..9, context menu (close, close others, pin). Programs save and restore `Tab` values. |
| Themes | `theme.rs` | light, dark, high contrast, any accent, scale 0.5–4, three densities; WCAG contrast checked in tests. |
| Strings | `i18n.rs`, `i18n/*.ftl` | a Fluent subset (variables, plurals by CLDR rules, selectors). English and German built in. |
| Accessibility | `a11y.rs` | AccessKit tree: node id = widget index + 1, window root = 1, overlays as children (Menu, Dialog with modal, Status, Tooltip). List rows, tabs and menu-bar titles are part nodes. First update is the whole tree, later ones only changes plus focus. `encode`/`decode` is the wire for `sex_pdx::a11y` (Whisper, thread S), `Ui::a11y_action` does Click, Focus, SetValue, Increment, Decrement, Expand, Collapse, ScrollIntoView. |
| SexOS glue | `sexos.rs` (feature `sexos`) | `App::open(title, theme, strings)`, `App::next()` (waits for input or Weft's next timer, paints, returns responses), event conversion. |

## Using it

```rust
let mut app = weft::sexos::App::open("Abacus", Theme::light(), Strings::new("en"));
let ui = &mut app.ui;
ui.commands.add(Command::new("app.save", "Save").shortcut("Ctrl+S").icon("save"));
let root = ui.root();
ui.menubar(root, vec![Menu::new("File").command("app.save")]);
let name = ui.field(root, "", "Name");
let ok = ui.button(root, "OK");
loop {
    for r in app.next() {
        match r {
            Response::Clicked(id) if id == ok => { /* … */ }
            Response::Command(c) if c == "app.save" => { /* … */ }
            Response::Close => sex_pdx::task_finish(0),
            _ => {}
        }
    }
}
```

`cargo run -p weft --example gallery -- out.png [dark|hc] [de]` paints every widget to a
PNG on the host.

## Gates

- `cargo test -p weft`: layout, focus order, hit testing, field editing and clipboard,
  a million-row table (End, Shift+Up, Ctrl+A, paint under 3 s in debug), document tabs
  (switch, close, new, drag to reorder, pin, tear off), menus by key and pointer, the
  palette, dialogs (save changes, confirm, prompt, colour), German strings, damage-only
  repaint, the accessibility tree golden and wire round trip, scroll views.
- `cargo test -p abacus --no-default-features`: the calculator's evaluator and window.
- `scripts/program_weft_gate.py` (CI runtime job): boots SexOS, runs Abacus, types
  `12`, clicks `+`, types `30`, Enter → `42`; clicks `7 × 6 =` → `42`; `1/0` → error;
  Ctrl+Shift+P, `radi`, Enter → the Radians command.

## Not yet

- Pointer modifiers: Shell's pointer events carry no Shift/Ctrl, so Ctrl-click and
  Shift-click selection in lists use the keyboard only (Ctrl+Space, Shift+arrows).
- Multi-line text editing (Quil keeps its own editor for now), rich text, bidi shaping.
- Tear-off makes `TabEvent::TornOff`; moving the tab into a new window and dragging it
  back to another window's strip needs Shell's drag-between-windows (M12, with thread C).
- The theme is the program's choice; reading the desktop's appearance settings waits for
  that setting to exist in Shell.
- Drag and drop between widgets, date and time pickers, a tree model helper.
