## What is already on master (PRs #47 and #63)

- J1 code pages: `SYS_PROGRAM_CODE` 82, `sex_app::code::CodeBuf`. Sealed code may not
  contain WRPKRU/XRSTOR/XRSTORS bytes.
- J3 threads: `SYS_PROGRAM_THREAD` 83 (spawn/exit/wait with ms limit/wake/cores/TLS),
  `sex_app::thread`.
- J4: user CPU faults end only the program.
- J5a TLS: per-task FS base, `sex_app::tls`.
- J5b pthreads in `crates/sex-libc/src/pthread.rs`.
- J5c (PR #63) C++:
  - `scripts/build_libcxx.sh` builds libc++/libc++abi (LLVM 18.1.8, no exceptions) into
    `target/libcxx`, over musl headers (`apt install musl-dev`).
  - `crates/sex-libc` supplies locale, wchar, atexit, constructors, and the futex syscall.
  - `apps/cpp` + `scripts/program_cpp_gate.py` show the pattern: a Rust `_start` program,
    plus a `build.rs` that compiles C++ with clang `--target=x86_64-unknown-none-elf`
    and links libc++ with `--no-dependent-libraries`.

## Policy (Andreas)

Rust everywhere except ported engines. V8 lives in its own organ (key domain). The
kernel, servers, SDK and browser stay Rust.

## Suggested route

1. Source:
   - V8 `15.9.122` (GitHub mirror v8/v8, matches chromium of 2026-11-09).
   - Deps from DEPS via googlesource: build, buildtools, abseil-cpp, simdutf, zlib,
     highway, fp16, fast_float, dragonbox.
   - gn binary from CIPD, or built from gn.googlesource.com.
2. args.gn:
   - `v8_enable_i18n_support=false`, `v8_jitless=true` first, `is_component_build=false`
   - `use_custom_libcxx=false` (use target/libcxx), `v8_monolithic=true`
   - `treat_warnings_as_errors=false`, `v8_enable_sandbox=false` at first
   - `target_os="linux"` with musl-style flags, or a new `sexos` toolchain.
3. Platform:
   - Either a `src/base/platform/platform-sexos.cc`, or POSIX shims in sex-libc that map
     mmap/mprotect/munmap onto `SYS_PROGRAM_MEMORY`/`SYS_PROGRAM_CODE`.
   - pthreads and the clock are already there.
   - JIT tiers (Sparkplug/Maglev) need code pages to be W^X toggled. CodeBuf seal/open
     already gives this.
4. Proof:
   - `run v8` evaluates JS (e.g. a fib benchmark), compared against sex-js/QuickJS.
   - Then wire it into the browser behind a flag.
