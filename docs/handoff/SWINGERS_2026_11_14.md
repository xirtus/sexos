# Swingers: the SexOS BitTorrent engine (workstream X), 2026-11-14

Swingers is the BitTorrent client; `crates/sex-torrent` is its engine, a `no_std` + `alloc`
library with **no I/O**. Every protocol is a state machine: the program that embeds it owns the
sockets, files, clock and randomness. That keeps the engine testable on the host and keeps the
network grant (for example "only through the WireGuard tunnel", X7) in the program, where no
code path can open its own socket around it. Qupid and Kaleidoscope embed the same crate.

Host tests: `cargo test -p sex-torrent` (CI step "BitTorrent engine (sex-torrent)"), 218 tests.

## What is in the crate

| Module | What | Plan slice |
| --- | --- | --- |
| `bencode` | decode with exact byte spans (info-hash), canonical encode, depth/size limits | X1 |
| `metainfo`, `merkle`, `magnet`, `create`, `adapt` | v1, v2 (BEP 52), hybrid (BEP 47 pads) torrents; merkle trees, hash requests and proofs; magnets (btih, btmh, `so`, `x.pe`); making torrents (byte-identical to libtorrent's v2 test torrents); layout and verifier for the session | X1, X8 |
| `peer`, `extension`, `picker`, `storage`, `resume`, `session` | peer wire (BEP 3, 6 fast, 10, 52 hash messages), ut_metadata, ut_pex, lt_donthave, upload_only; rarest-first picker with end game, sequential, priorities and **streaming deadlines / playhead**; part files so deselected files are never written; write cache; resume data; `Torrent` and a `Session` that scales to 10,000 torrents (idle torrents cost nothing per tick) | X1, X4, X5, X10 |
| `stream` | the protocol Qupid uses to read byte ranges from Swingers, and the planner that turns play position + bitrate into piece deadlines (header and footer pinned, window ahead, seek moves it) | X5, Qupid Q11 |
| `tracker`, `dht`, `lsd`, `webseed` | HTTP/UDP trackers, tiers, scrape; Mainline DHT with IPv6, BEP 42 secure ids, read-only mode; Local Service Discovery; web seeds (BEP 19) | X1, X2 |
| `utp`, `ledbat`, `mse`, `portmap` | uTP with selective acks and LEDBAT (queue stays under ~200 ms on a simulated line); protocol encryption (RC4/DH); PCP, NAT-PMP, UPnP IGD port mapping | X3 |
| `rss`, `torznab`, `rules` | RSS/Atom feeds, Torznab client and multi-indexer merge/rank (shared with Qupid Q11b), qBittorrent-style rules with episode filters and smart episode detection | X6 |
| `rpc`, `webui` | Transmission-compatible RPC (409 session id, basic auth, torrent-get/add/set/...), embedded web UI | X9 |
| `bandwidth`, `anonymous` | token buckets with fair share, alt-speed schedule, seeding ratio/time rules, queueing; anonymous mode policy and an `audit` for outgoing bytes | X7, X10 |
