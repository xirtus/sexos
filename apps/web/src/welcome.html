Web, the SexOS browser

HTML parsed, styled with CSS and laid out in this program, drawn with Geist.

What works

HTML

Forgiving parser: implied tags, entities & tables.

CSS

Selectors, cascade, !important, media queries.

Layout

Blocks, lines, lists, tables and flex rows.

Text flows in proportional Geist Sans, with emphasis, underlines, strikes, code in Geist Mono and links you can follow. Press → and ← to move between links and Enter to open one.

  1. Type / then an address to go there
  2. Up, Down and Space scroll
  3. Backspace goes back
KeyDoes
→ / ←Next or previous link
EnterOpen the link
F11Close

Pages from the internet need the network: start with run +net web https://example.com.

Pages run JavaScript (QuickJS on Wasm) and draw on Canvas 2D. Try them in the games.
