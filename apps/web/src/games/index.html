Games

Small classic games, written for SexOS in JavaScript on Canvas 2D, WebGL and three.js.

Solitaire

Klondike, draw one. Arrows move, Enter picks up and puts down, Up takes more cards, Space draws, A sends a card home.

Chess

You play White against the computer. Arrows move, Enter picks a piece and its square, L changes the level.

Maze

Walk a brick maze in 3D (WebGL) and find the gold. Up walks, Left and Right turn, A walks by itself, N makes a new maze.

3D Chess

The same chess on a three.js board with turned pieces. It takes a while to load three.js.

XIRTUS Pinball

A haunted night table: skull bumpers, coffin slingshots and a crypt. Left and Right flip, Space launches the ball.

Press → to pick a game and Enter to start it. Backspace in a game is undo; F11 closes. Programs run solitaire, run chess, run chess3d, run maze and run pinball open them directly.
