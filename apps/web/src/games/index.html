Games

Small classic games, written for SexOS in JavaScript on Canvas 2D.

Solitaire

Klondike, draw one. Arrows move, Enter picks up and puts down, Up takes more cards, Space draws, A sends a card home.

Chess

You play White against the computer. Arrows move, Enter picks a piece and its square, L changes the level.

Press → to pick a game and Enter to start it. Backspace in a game is undo; F11 closes. Programs run solitaire and run chess open them directly.
