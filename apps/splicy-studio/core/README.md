# Splicy's editing core

The engine and interface of Splicy Studio. They began as FilmCraft
(github.com/storytold/filmcraft at commit e63e1d7), whose code is MIT OR Apache-2.0: see
LICENSE-MIT, LICENSE-APACHE, NOTICE and ATTRIBUTION.md here, which stay with the code.

Splicy carries only its own name: FilmCraft's and ArtCraft's names, logos, Discord, website
links and updater are gone from everything a user sees and from the files Splicy writes.
FilmCraft's tests, examples and tools stayed upstream; only the crates Splicy builds are here.
Crate names (`filmcraft-*`) are unchanged so the code still lines up with upstream when we
take later fixes from it.
